# 支出憑證紀錄系統 v1.0 使用手冊

適用對象：如果建築師事務所的上傳同仁、管理者及受授權會計人員。

## 1. 系統用途與儲存方式

本系統整理支出憑證、原始附件、用途、分類、金額及檢閱歷程。v1.0 使用伺服器上的 SQLite 資料庫與附件目錄；同一伺服器的授權使用者可跨裝置使用資料。瀏覽器重新整理、登出或換電腦不會刪除伺服器已儲存的資料。

服務必須運行，才能登入或讀取資料。部署在 NAS 時，NAS 需要保持運作。請使用管理者提供的 HTTPS 網址；手機與桌面瀏覽器共用同一套系統。v1.0 不提供本機示範角色切換作為登入方式。

系統不處理收入、付款對帳、薪資計算或正式財務報表，也不自動認定可扣稅金額。建築師事務所的執行業務身分、憑證要求及列報方式應由會計師確認。

## 2. 登入與角色

帳號由受信任的系統管理人員建立，沒有公開註冊或共用預設密碼。輸入帳號及密碼後登入；完成作業請登出。密碼遺失時，聯絡管理者透過伺服器維護工具重設，勿透過電子郵件或 AI 對話傳送現有密碼。

| 角色 | 可使用功能 |
|---|---|
| 上傳同仁 employee | 新增支出、上傳附件、查看本次送出結果；不能查看支出清單、統計、匯出及其他人的憑證。 |
| 管理者 manager | 支出總覽、搜尋、附件下載、修改、內容檢閱、CSV 及完整資料備份。 |
| 會計人員 | 需要直接操作時，由公司授權建立 manager 帳號；此權限可看全部支出，並非唯讀。亦可只收取管理者匯出的資料。 |

閒置或登入期限屆滿後需重新登入。權限在伺服器檢查，修改瀏覽器畫面或本機儲存值不會取得管理者權限。

## 3. 新增支出

1. 選擇「新增支出」。
2. 點「選擇檔案」加入掃描檔、照片、PDF 或其他原始附件；手機可使用「拍照」。同一筆支出可附多份，不同支出應分筆建立。
3. 填寫商家／收款對象、憑證日期、支出總金額、幣別、憑證類型、分類與用途。有發票或憑證號碼時一併填寫。
4. 依實際情況補充參與人員、車輛及工作用途、訂閱期間或其他說明。餐飲可註明工作餐、客戶招待或個人消費；分類本身不是扣稅核准。
5. 按「儲存支出」，確認成功訊息及紀錄編號。失敗時保留畫面及訊息，先確認是否已送出，避免重複建立。

每筆至少一份附件；每份附件最多 25 MB，單次新增附件最多 20 份，整筆請求另有伺服器大小限制。不同支出請分筆；同一筆支出的附件若超過上限，請聯絡管理者處理，勿重複登錄金額。金額應大於零，最多兩位小數，依原幣總額填寫；系統不自動拆算稅額或匯率。

目前 OCR 尚未啟用，請依原始憑證手動確認欄位。無法在瀏覽器預覽的 HEIC 或其他格式仍可保留原檔，管理者下載後使用相容軟體開啟。副檔名與畫面預覽不代表憑證真實性驗證。

## 4. 總覽、查詢及檢閱

管理者可在「支出總覽」選擇月份及幣別，查看已紀錄支出、已檢閱金額、待檢閱筆數與分類分布。不同幣別不合併為單一金額；已紀錄總額可能包含待檢閱項目。

「憑證紀錄」可依商家、用途、備註、憑證號碼搜尋，並以月份、分類、幣別及狀態篩選。開啟紀錄後可查看附件、SHA-256 校驗碼及伺服器紀錄的修改歷程。

檢查附件、日期、金額及用途後，選擇「標記已檢閱」。「已檢閱」代表內容已確認，不代表會計師、稅捐機關核准，亦不代表已完成報稅。

## 5. 修改及更正

管理者開啟紀錄後選「編輯紀錄」。已檢閱紀錄必須填寫修改原因，更正後回到待檢閱。原始附件保留，伺服器另存修改版本與操作者資料。

若顯示資料已被其他人更新，請重新開啟紀錄、比對最新內容再修改。不要連續重送舊畫面。系統未提供一般使用者永久刪除原始憑證的功能；誤登或重複項目應在備註清楚標示並交由管理者處理，匯出時向會計師說明。

## 6. 提供資料給會計師

「匯出與備份」提供 CSV，或從憑證清單匯出目前篩選結果。CSV 包含金額、原幣、分類、用途、附件名稱與校驗碼，但不含附件本體。請另下載完整 JSON 資料包，內含原始附件；JSON 需以相容工具解讀，並非政府申報檔。

完整資料包包含敏感財務資料，只提供給獲授權者。請與會計師確認交付格式、篩選範圍與未檢閱項目。系統沒有自動寄信或自動傳送會計師的功能。

## 7. 備份與復原

管理者可下載完整資料包保存交付快照。正式災難復原應由公司備份整個持久資料目錄，包含資料庫與原始附件；只備份程式碼或 CSV 不足以還原系統。

建議每天備份到另一個受控位置，定期在隔離環境測試還原。直接複製運作中的 SQLite 檔案可能不一致，請依部署交接文件採停機一致性備份，或經驗證的資料庫備份程序。NAS 磁碟陣列不等於獨立備份。

v1.0 不在一般操作畫面直接覆寫伺服器資料庫。復原、舊原型匯入、帳號重設與伺服器搬遷由受信任維護者執行，完成後重新核對筆數、附件及金額。瀏覽器原型的資料不會自動搬入 v1.0。

## 8. 常見問題

- **不能登入**：確認網址、帳號與密碼；請管理者確認帳號啟用狀態。重複錯誤登入可能暫時受限制。
- **連不上系統**：確認 NAS、容器、公司網路／VPN、反向代理及 HTTPS 憑證。勿略過瀏覽器安全警告。
- **手機不能拍照**：確認 HTTPS、瀏覽器權限；也可先用手機相機拍攝，再選檔上傳。實機功能需在公司設備驗收。
- **上傳失敗**：確認大小、網路與儲存空間；依錯誤訊息處理，勿假設失敗檔案已安全保存。
- **無法預覽**：下載原始檔，用適當軟體開啟。
- **不能扣稅或缺少必要資訊**：保留事實與證明，交由會計師判斷；勿因無法扣稅就刪除實際支出。
