# v1.0 驗證紀錄

開發機驗證日期：2026-10-31。所有使用者與支出均為隔離測試資料；沒有公司正式帳號或 NAS 資料。

- JavaScript：10 個自動測試通過，含金額、日期、幣別、CSV 公式防護、SHA-256、備份校驗及歷史 adapter 契約。
- Python 後端：16 個實際 HTTP 整合測試通過，含無預設帳號、匿名／employee 財務存取阻擋、原檔內容／路徑隔離、更正與版本衝突、附件校驗、寫入失敗回復、CSRF／Origin、備份不含登入機密、重設及角色變更撤銷 session、密碼與 session hash、登入節流、HTTPS cookie 設定、重新啟動持久化、登出與閒置失效。
- 瀏覽器：正式版先顯示帳密登入頁，以臨時 QA 帳號登入，透過選檔上傳公司標誌作為測試附件，建立 NT$123.45 測試支出；伺服器回傳成功，清單及總覽顯示一筆紀錄與附件。截圖為 docs/v1-dashboard.png。
- 前端語法檢查與靜態資源打包通過。
- 稅務／使用手冊文字已覆核，已更正避免將一筆支出因附件過大而重複登帳的說明。

未驗證：Docker 映像實際啟動（開發機未安裝 Docker）、公司 NAS 架構／掛載權限、正式 HTTPS 反向代理、公司帳號與備份排程、NAS 災難還原、實際 iPhone 相機／HEIC 裝置相容性。請依部署交接文件在公司端驗收。未設定 OCR 供應商。
