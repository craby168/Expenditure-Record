# 給後續 AI／公司維護者的部署交接

## 系統與邊界

這是如果建築師事務所的「支出憑證紀錄系統」。`prototype` 分支保存瀏覽器 IndexedDB 示範版；`v1.0` 使用同源 Python 後端、SQLite、伺服器私有附件及實際帳密登入。單一事務所、初期少於五人。繁體中文、手機與桌面響應式介面。

employee 僅能新增支出，不可列出紀錄、讀取附件、統計或匯出。manager 可管理支出；會計師若設 manager，即獲全部管理者財務操作權限。沒有公開註冊、預設帳密或正式版角色切換。

未實作收入、付款對帳、正式帳簿、法定報表、稅額計算、OCR 供應商、郵件找回密碼。不要把這些當成已完成。建築師可能屬執行業務者，適用稅制未確認；參閱 `docs/tax-profile-addendum.md`，不要直接啟用舊營利事業稅務假設。

## 公司端必須確認的事項

1. NAS 品牌／CPU 架構、作業系統、Docker／Container Manager 支援、可用記憶體及持久磁碟路徑。
2. 正式網址、DNS、HTTPS 憑證、反向代理與公司 VPN／網路存取政策。建議內網或 VPN，若要公開上網需另外評估安全防護。
3. 受信任部署管理人員、第一位 manager、同仁帳號、實際備份位置及管理權限。
4. 備份排程、容量監控、還原責任人、會計師的欄位與交付要求。

不要要求使用者把 NAS 管理密碼、登入密碼、私鑰或機密金鑰貼到 AI 對話。由公司人員在本機終端輸入秘密。程式庫只能放 `.env.example`，不得提交 `.env`、資料庫、憑證或備份。

## 部署方向

- 使用 `Dockerfile` 與 `compose.yaml`。反向代理只對接應用程式埠，資料目錄以持久 volume 掛載；程式與資料分開。
- `APP_DATA_DIR` 指向容器持久資料目錄；公司人員決定 NAS 主機上的實際掛載路徑及權限。SQLite 應放在 NAS 主機本地檔案系統，不要讓多台應用程式透過 SMB/NFS 共用同一個即時資料庫。
- `APP_PUBLIC_ORIGIN` 必須是使用者真正開啟的 HTTPS origin；反向代理保留正確 Host／來源，設定適當請求大小與逾時。不要為了讓請求通過而任意放寬來源檢查。
- 正式環境 `APP_DEV_LOCALHOST=0`，cookie 使用 Secure。僅限同機迴路測試才開啟開發選項，不能把開發設定直接搬上 NAS。
- 使用後端 CLI 在公司端互動建立帳號／重設密碼。不要建立通用預設密碼；不要把密碼放在命令列參數、日誌或 Git。
- 驗證帳號停用、登出、逾時、employee 權限、manager 更正、附件下載、並行版本衝突與服務重啟後資料仍存在。

API 與靜態介面必須同源。前端 `server-store.js` 呼叫 `/api/*`，以 HttpOnly session cookie 登入，變更請求附 CSRF token。資料與附件永遠經授權 API 讀取，不可把附件目錄設為 NAS 公開網頁資料夾。

NAS 沒有 Docker 時，確認支援相容 Python 與 SQLite，以受限服務帳號執行 `python -m backend.app serve`，接在 HTTPS 反向代理之後，並配置作業系統服務自動啟動。實際命令以後端 `--help` 與 README 為準。

## 備份、搬遷與舊資料

每天備份資料庫與原始附件，兩者要一致。最簡單的維護流程是停止容器、備份整個持久資料目錄、重新啟動；制定可接受的停機時段。至少一次在另一個隔離目錄還原並核對筆數、附件 SHA-256、不同幣別金額及帳號權限。備份應加密或放受控目錄，且有另一個故障邊界。

prototype 的瀏覽器資料不會自動移轉。若公司要匯入原型備份，先另存原始備份，在測試資料目錄以經審核的維護腳本驗證附件校驗碼、資料關聯與重複編號，再匯入；不要把未驗證的 JSON 直接覆寫正式資料庫。v1.0 的 JSON 匯出是交付快照，不能取代完整資料庫備份及還原驗證。

## 可客製項目

標誌 `assets/company-logo.jpg`、文字與配色、分類清單、幣別、必填欄位、會計師 CSV 欄位、工作用途提示、session 時限、備份排程。分類或欄位變更時，同步調整前端及後端驗證，並規劃歷史資料相容性。

OCR 可增加伺服器端供應商 adapter；金鑰不能送進瀏覽器，紀錄來源／模型版本並保留人工確認。需要更高隱私時可替換為 NAS 本機 OCR。真正開始傳送公司憑證前，確認公司對供應商與資料處理地點的授權。

## 驗收與限制

先跑自動測試，再在 NAS 實機驗收：HTTPS／來源設定、手機相機與 HEIC、多人使用、容量不足、重啟持久化、備份與還原、反向代理請求上限及錯誤處理。開發機通過測試不能代表公司 NAS 已部署完成。

本專案沒有存取公司 NAS 或建立正式帳號；這些是公司端必須完成的設定。不得為了趕上線關閉登入、改用角色下拉選單或公開資料目錄。
